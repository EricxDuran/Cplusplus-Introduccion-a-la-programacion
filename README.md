## ¿De qué va esto?

Este es el lugar donde voy subiendo todos los ejercicios y prácticas que hago para la clase de Introducción a la Programación. Todo el código que vas a ver aquí está escrito en C++.

Básicamente, lo uso para guardar mi progreso mientras aprendo. Hay desde cosas súper básicas para pillar el truco a las variables y los bucles, hasta temas un poco más enrevesados como la recursividad (como el famoso problema de las Torres de Hanói) o pequeños algoritmos matemáticos.

## ¿Qué vas a encontrar aquí?

* **Lo básico:** Uso de variables, condicionales (`if` / `else`) y bucles para repetir cosas (`while`, `for`).
* **Funciones:** Cómo dividir el código para que sea más limpio y usar librerías matemáticas básicas.
* **Ejercicios prácticos:** Pequeños programas como simular el lanzamiento de una moneda, calcular tarifas de un parking, aproximar el valor de PI o cifrar y descifrar números.
